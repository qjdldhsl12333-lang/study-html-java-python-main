기본생성자를 정의하지 않음 컴파일러가 자동으로 만듬 ->우리눈엔 안보인다했음

객체를 만들 때 필드에 초기값을 바로 넣고 싶을 때 매개 변수를 이용해
값을 받을 수있다.

생성자 오버로딩
매개값으로

Car(String model, String color) { ... }
Car(String color, String model) { ... } //오버로딩이 아님 컴파일 에러 발생

컴파일러가 생성자를 읽을 때 매개변수의 타입만 읽는다.
-객체를 메모리에 올린다
- 객체를 만들면서 전달한 값을 필드에 초기화

메서드 선언
- 메서드는 크게 **선언부(signature)와 실제 영역(body)**로 구성되어 있다.

접근 제한자 ^ 반환타입 ^ 메서드명(){

}

static 필드
static 메서드
 정적 필드, 정적 메서드
자바의 메모리 영역중 method 영역에 올라간다.
메모리에 한번만 기록이 되고
객체들은 method 영역에 올라간 정적필드의 값이나 메서드를 공유한다.

main에서 실행 할 때 정적필드, 메서드를 메모리에 먼저 올려놓고 시작하기
때문에 너무 많은 static은 로딩에 지연이 걸릴수 있다.

정적필드의 사용

정적필드는 객체 생성을 하지 않고 클래스명.필드명으로 사용이 가능하다.
