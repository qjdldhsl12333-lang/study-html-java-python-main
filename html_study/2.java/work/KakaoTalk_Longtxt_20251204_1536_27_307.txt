⭐ 1. 정보처리기사 (최우선)

✔ 실무 취업 시 제일 도움 됨
✔ 기업 인사팀이 가장 알아보는 자격증
✔ 개발 기본지식 정리 + DB/OS/네트워크/자료구조 전반 포함
✔ 정연 이미 공부 거의 반쯤 했음

📌 백엔드 취업 준비 = 정보처리기사 + 포트폴리오 조합이 제일 국룰

⭐ 2. SQLD (SQL 개발자)

✔ 데이터베이스 필수인 백엔드에게 직결
✔ MySQL / Oracle / MariaDB 다 기본 원리 같음
✔ 조인–서브쿼리–인덱스 개념 정리 가능
✔ 신입 백엔드 실력 인증 + 면접에서 도움됨

정연 지금 DB 공부 엄청 열심히 해서 이거 바로 목표로 잡아도 됨.

⭐ 3. 리눅스 마스터 2급

✔ 백엔드·서버 환경 기초 이해에 도움
✔ 필수는 아님
✔ AWS/Docker/Kubernetes로 넘어가기 전에 개념 잡히면 좋음
✔ 서버 띄우는 법, 권한, 프로세스 개념 등 가볍게 터치

⚠️ 하지만
실무에서는 리눅스 자격증이 필수는 절대 아님.
할 수 있으면 하고, 아니어도 상관 없음.

⭐ 4. AWS Cloud Practitioner (CLF) / SAA

(외국계·클라우드 기반 회사 노릴 때)

✔ 백엔드 취업 시 가산점 큰 편
✔ 서버 인프라 이해 올라감
✔ 스프링 + AWS 조합 많이 씀
✔ DevOps로 확장할 때도 유리

초반에는 굳이 필요 없지만
정연이 스프링 배운 뒤 AWS 띄우기 시작하면 괜찮은 선택.

⭐ 5. TOEIC(선택)

✔ IT 기업은 영어 점수 크게 보진 않음
✔ 하지만 외국계, 대기업 일부는 요구함
✔ “있으면 좋고 없어도 ㄱㅊ”
