3. 재고(stock)가 20 이하인 모든 상품의 가격(price)을 10% 인상하시오.
단, 인상된 가격은 반올림 없이 정수만 사용하시오. (예: price = price * 1.1)

내가쓴답
select stock, price
from product
group by stock
having price= price * 1.1;

정답 
UPDATE PRODUCT SET price = price * 1.1 WHERE stock <= 20;

4. 가격이 10000원 미만 또는 재고(stock)가 30 미만인 상품을 모두 삭제하시오.
단, 무선마우스(101)는 삭제하지 않는다는 조건을 반드시 포함하시오.

4. DELETE 정답
DELETE FROM PRODUCT WHERE (price < 10000 OR stock < 30)  AND id <> 101;

10.가장 비싼 상품 가격보다 가격이 낮은 상품들의 이름과 가격을 조회하시오
서브쿼리로 최대 가격을 구한다
그 최대 가격보다 작은(price < 최대값) 상품만 조회한다
SELECT
   name,
   price
FROM PRODUCT //최대= MAX 가격= price 니까 MAX(price)
//서브쿼리로 구하는거니까 where절 앞에 와야겠지?

WHERE price < ( //서브쿼리로 최대 가격을 구한다
   SELECT MAX(price) // (price < 최대값)  상품만 조회한다
   FROM PRODUCT
);
