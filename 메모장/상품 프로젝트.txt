//-----------------------------------------------------------------------------
API Application Programing Interface 
ㄴ 서로 다른 프로그램들이 데이터를 주고받고 기능을 공유할 수 있도록 돕는
'규칙과 약속의 집합'
//-----------------------------------------------------------------------------
JPA(Java persistence API) 인터페이스형식으로 작성
자바 프로그램에서 데이터를DB에 저장하기 위한 기능

자바객체랑 관계형 데이터베이스 사이를 연결하고, 
(findAll()-> select * from 테이블;)
개발자가 직접SQL을 작성하지 않고도 객체를 DB에 CRUD할 수 있도록한다.
객체 (Object)와 테이블(Relation)을 매핑(Mapping)해준다.
이를 ORM(Object-Relational Mapping)기술이라한다.

개발자가 따라야 할 API와 사용해야할 어노테이션을 정의한다.

모든 JPA구현체는 표준을 따라야 하므로, 
특정 구현체에 종속되지 않고 어플리케이션의 이식성을 높일 수 있다.
//------------------------------------------------------------------------------
ORM
ㄴ객체 지향 프로그래밍 언어의 객체와 관계형 데이터베이스의 
테이블을 자동으로 연결 (Mapping) 해주는 기술 또는 도구

JPA와 Hibernate의 차이점
JPA -> 인터페이스 공통적인 행동에 대한 정의
Hibernate ->구현체라면 인터페이스의 메서드를 다 구현
ㄴ JPA 표준에는 없지만 개발 편의성을 높이기 위한 고유의 기능도 가지고있다.

SQL Mapper
Mybatis : 객체랑 SQL결과를 매핑하는 기술 
ㄴ 개발자가 SQL을 직접 작성해줘야 한다.
ㄴ 복잡한 쿼리를 작성할 때 좋다.
ㄴ SQL을 직접 작성하기 때문에 직관적으로 어떤 데이터가 올 지 알수있다.
//-----------------------------------------------------------------
Mapping
한 데이터의 집합이나 구조의 요소를
 다른 데이터의 집합이나 구조의 요소와 
 연결시키는 과정을 의미하는 개념
ㄴ 요청할 때 URL 전달-> Controller 메서드를 연결
//-----------------------------------------------------------------
Hibernate
JPA 인터페이스를 구현한 구현체(implements)중 하나.
JPA에 정의된 모든 기능을 실제 코드로 구현하고, 
이를 수행하기 위해 내부 엔진을 제공

ㄴSQL변환 : 개발자가 작성한 엔티티 상태 변경이나 JPQL을 실제 
데이터베이스에 맞는 SQL 쿼리로 변환하여 실행합니다.

ㄴDielact : 다양한 데이터베이스(MYSQL, Oracle 등) 미묘한 차이점을 
처리하기 위한 방언 기능을 제공한다.
